# Claude Code Play

A browser game for studying Claude Code and Claude API concepts from the certification track (CCA and CCDV-F).

Play: https://beomyongjunprofile-dev.github.io/claude-code-play/

- Wire agents from the queue to DEPLOY and attach hooks, schemas, caching and other parts to stop hallucinations, leaks and token blow-ups within a budget.
- 23 levels in 7 chapters. Guided levels rewind on failure and explain why. HARD levels give only a diagnosis and hints.
- A short review round after each guided level covers exam points the board does not play.
- English, Korean and Japanese.

Single self-contained HTML file. Progress is stored in the browser only.

Unofficial study game. Not affiliated with or endorsed by Anthropic. Prices and behaviour are simplified for play.
